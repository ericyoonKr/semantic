# 기억으로 쓴 근거 차단을 Rust 함수로 옮김 (2026-11-13)

## 무엇을 바꿨나

- 새 크레이트 `crates/citegate`
  - `mentions(문장)`: 문장에서 조문(「」로 감싼 이름 포함, 제N조의M, 제K항), 별표·서식, 사건번호를 찾는다.
  - `ReadSet`: 대화에서 읽은 조문·별표·판례. 조문은 원문의 ①②… 로 항 번호까지 기록한다.
  - `check(문장, 읽은 것)`: 읽지 않은 조문·별표(`unit_not_read`), 원문에 없는 항(`paragraph_not_read`), 읽지 않은 판례(`case_not_read`)면 막는다.
- 검색 서버
  - `src/readlog.rs`: 대화 ID(`x-thread-id` 머리글)별 읽은 기록. 메모리에만 두고 24시간·1만 대화를 넘으면 지운다.
  - 기록하는 곳: `GET /laws/unit`(본문의 항 번호까지), `GET /cases/{id}`, `GET /laws/annexes`(목록의 모든 별표), `POST /annex/lookup`, `POST /sessions/{sid}/judge`(판정 결과에 적힌 조문).
  - 새 경로 `POST /answer/check` `{thread_id, sentences}` → 문장마다 `{ok, reasons}`. 한 번에 200문장까지.
  - 새 경로 `GET /laws/annexes?law=` → 법령 하나의 별표·서식 전체 목록.
- 에이전트
  - 모든 검색 서버 호출에 `x-thread-id`(대화 ID)를 붙인다(`tools/client.py` `THREAD_ID`).
  - `api/answer_gate.py` `SentenceGate`: 문장을 잘라 `/answer/check`에 묻고, 막힌 문장은 빼고 안내 한 줄을 넣는다. 파이썬 쪽에는 `[근거 N]` 표시가 원장에 있는지와 표시 바꾸기만 남겼다. 검색 서버가 응답하지 않으면 조문·별표·사건번호가 든 문장은 모두 뺀다.
  - 저장되는 답과 화면에 나간 답이 같도록, 검사는 게이트웨이가 아니라 에이전트가 답을 내보내는 자리에서 한다.
  - `[researcher]를 통해`처럼 도구 이름 바로 뒤에 조사가 붙으면 지우지 않고 우리말 이름(조사 등)으로 바꾼다.
- 게이트웨이: 하루 사용량 한도 검사와 그 문구를 뺐다(사용자 결정 2026-11-13). 사용량 기록은 남는다.

## 잰 것

- Rust 표본: 통과해야 할 24문장 중 잘못 막음 0, 막아야 할 27문장 중 통과 0. 별표 표본 10문장 모두 맞음.
- 떠 있는 서버에 실제 대화(김밥집 식중독 질문, 24초)로 9문장을 넣음: 읽은 근거 3문장·일반 설명 1문장 통과, 읽지 않은 조문·별표·판례 5문장 막음. 같은 문장을 다른 대화 ID로 넣으면 막힘.
- 같은 실제 질문의 답에는 읽은 근거 3개만 나왔고 막힌 문장은 0개였다.

## 질문마다 조사 먼저 (같은 날 추가)

- `agent/research_first.py` `ResearchFirst`: 질문의 첫 모델 호출 대신 코드가 조사 하위 에이전트(`task`, 목적: 조회)를 부른다. 모델은 조사 결과를 받은 뒤에 답을 쓴다. 모델이 더 조사하려면 직접 부를 수 있다.
- 마지막 답에 화면에 보일 글이 없으면(생각 표시만 있는 경우 등) 한 번 다시 쓰게 한다(`EMPTY_ANSWER_NOTE`).
- 설정 `RESEARCH_FIRST`(기본 켜짐). 시험 도우미의 기본 `ResearchOptions()`는 꺼짐이라 기존 시험 대본은 그대로다.
- 실측: 「영업정지 처분 받으면 항고소송 대상 되는가?」 13초, 첫 줄 「예.」, 근거 행정소송법 제2조·대법원 2024두35989 판결, 「잠시만 기다려」 없음.

## 아직 안 한 것

- 읽은 기록이 메모리에만 있어 검색 서버를 다시 띄우면 이전 차례에 읽은 것이 사라진다. 그 뒤 차례에서 앞서 읽은 조문을 다시 쓰면 막힌다. 세션 DB에 두고 대화와 함께 지우는 방식은 아직 안 했다.
- 근거 번호 없이 법적 단정만 하는 문장(조문 번호를 쓰지 않은 기억 답)은 이 검사로 막지 못한다. 조사를 먼저 하게 해서 줄였지만, 그런 문장이 얼마나 남는지는 아직 재지 않았다.
- 조사 먼저로 질문마다 늘어난 시간은 표본으로 재지 않았다(실측 한 건 13초).
