# 2026-11-13 법령·판례 검색: 단위 벡터 갈래, 판례 벡터 끔, 흔한 조각 빼기 0.02

## 바꾼 것
- **항·호·목 단위 벡터 갈래**(`crates/retrieval/src/query/units.rs`, 새 파일)
  - `article_unit.embedding`을 질의 벡터와 가까운 순으로 고른다(HNSW, `embedding IS NOT NULL` 부분 색인).
  - 기준일 판본·법령 종류·법령 범위로 거른다.
  - 같은 조문에서 나온 단위는 조문 하나로 합쳐 순위 합(RRF)에 `unit-vector` 갈래로 넣는다. 맞은 단위 경로는 `matched_units`에 3개까지 싣는다.
  - 질의 임베딩은 조문 벡터 갈래와 함께 한 번만 만든다.
  - 서버 설정은 `CORPUS_UNIT_VECTOR=on|off`이고, 기본은 off이다(아래 표).
- **판례 벡터 갈래 끄기**: 서버 설정 `CORPUS_CASE_VECTOR=on|off`, 기본은 off이다.
  - 설정으로 끈 경우에는 결과를 「저하」로 표시하지 않는다.
  - `CORPUS_VECTOR_SEARCH=off`이면 전처럼 법령·판례 모두 끄고 저하로 표시한다.
- **흔한 조각 빼기 기본값**: `CORPUS_KEYWORD_MAX_DF`를 넣지 않으면 0.02이다(전에는 1.0, 빼지 않음).
- **판례 검색 단계별 시간 기록**: `case search stage` 기록에 `stage`(text·vector·keyword·cited·facts·hits)와 `elapsed_ms`를 남긴다.
- **`settle`**: 벡터 갈래 결과를 `Vec`이 아닌 아무 기본값 있는 형으로 받게 넓혔다. 법령 벡터 갈래가 조문 목록과 단위 목록을 함께 돌려주기 때문이다.
- **`KeywordSide` → `UnitSide`**: 키워드 갈래와 단위 벡터 갈래가 같은 「조문 + 맞은 단위」 모양을 쓰므로 이름을 바꿨다.
