# 2026-11-08 판례 자료가 없을 때 500 대신 알림

## 바꾼 것
- `crates/server/src/http/search.rs` `api_error`: 법령·판례 DB가 「표가 없음」(PostgreSQL 오류 코드 42P01)으로 답하면 500 대신 503으로 답한다. 없는 표가 판례 쪽 표(decision, decision_section, decision_chunk, decision_citation, court, section_role, extract_run, chunk_embedding, embedding_model, law_unit, law_unit_lineage)면 「검색 실패: 판례 자료가 아직 법령·판례 DB에 들어 있지 않습니다」, 그 밖이면 「검색 실패: 이 검색에 쓰는 자료가 아직 법령·판례 DB에 들어 있지 않습니다」.
- `agent/src/semantic_agent/tools/client.py`: 서버가 400·404·409·413·422·503으로 거절하면 응답 본문의 `error` 문구(200자까지)를 도구 결과에 싣는다. 전에는 모두 「지금 처리할 수 없음」이었다. 500은 그대로 「지금 처리할 수 없음」.

## 확인
- 서버를 띄워 판례 검색·판례 읽기·인용 관계 세 경로 모두 503과 위 문구가 오는 것을 봄(지금 DB에 판례 표 없음).
- 시험: server 단위 시험(판례 쪽 표 이름 → 문구), `server --test search` 5개, 에이전트 `test_real_tools.py`의 거절 까닭 시험 포함 12개 통과.
- 판례 경로의 인용 관계 조회는 옛 법령 표(law_unit, law_unit_lineage)도 쓴다. 판례 적재 때 함께 새 표로 바꿔야 한다.
