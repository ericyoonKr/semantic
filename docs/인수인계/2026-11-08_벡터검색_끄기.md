# 2026-11-08 벡터 검색을 설정으로 끄기

## 왜
- 법령 임베딩을 채우는 데 약 66.5시간(2026-11-08 20:42 시작, 11-11 15시 무렵 끝)이 걸린다. 검색은 벡터가 한 행이라도 있으면 벡터 후보를 쓰므로, 채우는 동안 일부만 찬 벡터(처음엔 「제n조 삭제」 같은 짧은 본문)가 후보로 올라온다.

## 바꾼 것
- 서버 ① 환경변수 `CORPUS_VECTOR_SEARCH`(on|off, 기본 on, 다른 값은 기동 실패). off면 법령·판례 검색이 질의 임베딩을 만들지 않고 글자 검색만 하며, 결과의 강등 까닭에 「벡터 검색을 설정으로 꺼 두어 글자 검색만 함」을 적는다.
- `retrieval`: `Corpus::without_vectors()`, 오류 `VectorOff`, 강등 문구 `VECTOR_OFF`.
- 실행 환경(저장소 밖)에서는 off로 두었다. 임베딩이 다 차면 on으로 바꾼다.

## 시험
- retrieval 단위(강등 문구), 실제 DB 시험 1개(끈 상태에서 법령 검색이 강등 까닭을 적음), 서버 설정 시험(off, 잘못된 값 거부, 기본 on) 통과. `server --test search` 5개 통과.
