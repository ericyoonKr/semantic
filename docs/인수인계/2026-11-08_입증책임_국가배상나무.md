# 작업 인수인계 — 2026-11-08 입증책임·감액 사유·국가배상 나무

## 사용자 결정 (2026-11-08)

1. 노드마다 입증책임(`plaintiff`/`defendant`)을 적는다. `pending`은 초안에만 남긴다. 판정 결과에는 사실대로의 결론과 입증책임을 적용한 결론을 나란히 적는다(설계서 §9.5).
2. 성립 여부를 바꾸지 않고 배상액만 줄이는 사유(과실상계)는 판정 문장에만 적고 Z3 결론에는 넣지 않는다(설계서 §9.5).
3. 행정에 관한 기간 리프는 기간 설명에 「행정기본법 제6조 제1항(특별한 규정이 없으면 민법 준용)」을 적는다. 같은 조 제2항의 기간은 계산 규칙 없이 판정 불가로 둔다(설계서 §9.2a).
4. 국가배상 요건 나무를 사용자 지식그래프에 맞춰 다시 그린다(설계서 §9.4). 원본 YAML과 빌드한 묶음은 저장소 밖에 둔다.

## 한 일

- engine
  - `Burden`에 `Plaintiff`·`Defendant`, `Relation`에 `Reduction`, `ArithSpec`에 `ElapsedYears`, 노드에 `period_rule`(`administrative`/`administrative_restrictive`), 근거에 `quote`를 더했다.
  - `check_both`: 사실대로 한 번 확인하고, 판정하지 못한 리프를 입증책임에 따라 거짓으로 고정해 한 번 더 확인한다. 고정하지 않는 것: 판정된 리프, 가정한 값, `pending`, 긍정·부정 쌍에서 `negation_of`를 가진 쪽, 상대가 판정되었거나 가정된 쪽.
  - `Verdict`에 `burden`(입증책임을 적용한 결론·불성립 이유·고정한 리프)과 `reductions`(감액 사유 리프의 값)를 더했다. 감액 사유 리프는 `unknown_leaves`에 넣지 않고, 판정하지 못하면 `needed_facts`에는 넣는다.
  - 적재 가드: `reduction` 간선의 자식은 `reduction` 간선으로만 이어진 LEAF여야 한다. `period_rule`은 `arithmetic`이 있는 리프에만 쓴다.
  - `elapsed_years`는 제소일이 말일을 지났으면 참이다. Z3에는 `리프 ⇔ ¬(제소일 ≤ 말일)`로 넣는다.
  - `administrative_restrictive` 리프는 모델을 부르지 않고 정해진 이유로 판정 불가.
- ruleloader: `period_rule`을 읽어 내보낸다. 계약의 관계 목록에 `reduction`이 들어간다. build 거부 문구에서 「결정 1 전」을 뺐다.
- server: 판정 문장 둘째 줄에 「입증책임을 적용한 결론」, 판정하지 못한 리프 줄 끝에 「(원고가 입증할 사실)」·「(피고가 입증할 항변)」·「(입증책임 미정)」, 감액 사유 줄, 기간 설명의 근거 줄. 응답 JSON의 `verdict`에 `burden_applied`·`reductions`, `unknown_leaves`마다 `burden`.
