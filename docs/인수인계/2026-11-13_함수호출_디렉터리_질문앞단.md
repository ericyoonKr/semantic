# 함수 호출 디렉터리와 질문 앞단 판정 (2026-11-13)

## 원칙 (사용자 결정 2026-11-13)

- 판정·검사·순서 규칙은 Rust로 짠다. Python은 deepagents 틀처럼 꼭 필요한 부분과 Rust 함수를 부르는 연결만 둔다.
- 코드가 부르는 함수는 한 디렉터리에 모은다.
  - Rust: `crates/server/src/funcall/`, HTTP 경로는 `crates/server/src/http/funcall.rs`
  - Python: `agent/src/semantic_agent/funcall/`

## 무엇이 어디에 있나

- `funcall/readlog.rs`: 대화(`x-thread-id`)별 읽은 조문·별표·판례 기록. 메모리, 24시간·1만 대화.
- `funcall/check.rs` → `POST /answer/check`: 문장마다 `{ok, reasons, unread}`. `unread`는 읽지 않은 조문·판례 이름.
- `funcall/next_step.rs` → `POST /sessions/{sid}/next-step` `{request_id, question}`: 다음 단계 하나를 낸다.
  - 두 글자 이상 낱말이 없거나 법률 질문이 아니면 `model`(모델이 바로 답함).
  - 아직 다루지 않은 올린 문서가 있으면 최신 문서부터: 2만 자 이하는 `read_file`(2,000줄), 넘으면 질문의 가장 긴 낱말로 `grep`.
  - 그다음 `task`(조사 하위 에이전트). 지시에 질문과, 문서에서 법령을 든 문장(1,500자까지)을 넣는다. PDF 줄바꿈 때문에 줄이 아니라 문장 단위로 고른다.
  - 한 차례(`request_id`)에 조사는 한 번, 그 뒤는 `model`.
- `funcall/route.rs`: 법률 질문인지 모델로 판정. 설정 `ROUTE_LEGAL=on`일 때만 쓴다(기본 꺼짐, 실패하면 법률로 본다).
- `funcall/docs.rs`: 세션 DB에서 올린 문서의 글과 크기를 읽는다.
- Python `funcall/first_step.py` `FirstStep`: 모델을 부르기 전에 next-step을 묻고, 단계가 `model`이 아니면 그 도구 호출을 그대로 낸다. 마지막 답에 보일 글이 없으면 한 번 다시 쓰게 한다.
- Python `funcall/readcheck.py` `ReadCheck`: `/answer/check` 호출(답 문장 판정, 문서 조문 중 안 읽은 것).

## 잰 것

- 법률 판정 표본 60개(법률 30·비법률 30, 직접 만든 질문): 놓침 0/30, 헛조사 0/30, 실패 0, 판정 시간 중간값 216ms·최대 839ms. 실제 사용자 질문으로는 아직 안 쟀다.
- 실제 처분서(수목원 공사계약, 2쪽) 「무슨 법?」: 문서 읽기 → 조사 → 지방계약법 제16·17·18조(2021-12-30 판본) 읽음, 근거 칩 3개, 19초.
- 도구 고정(tool_choice)은 지금 모델 서버에서 두 번 모두 무시됐다. 그래서 강제 단계는 모델을 거치지 않고 코드가 바로 낸다.

## 아직 Python에 남은 판정 (Rust로 옮길 것)

- 답 문장: `[근거 N]` 표시 대조, 문장 자르기, 내부 도구 이름 지우기(`api/answer_gate.py`), 보일 글이 비었는지(`funcall/first_step.py` `visible`).
- 조사 결과: 형식 해석, 반대 검색어 대조, 근거 대조, 검색 없이 끝남·문서 조문 안 읽음 되돌리기(`agent/delegation.py`, `agent/citations.py`).
- 범위 밖 질문 거절, 판정 경로, 반복 호출 막기(`agent/guards.py`, `agent/judge_route.py`, `agent/repeat.py`).
