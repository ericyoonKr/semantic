# 2026-11-08 모델 호출 제한(출력 상한, 대기 제한, 재시도)

## 바꾼 것
- `agent/src/semantic_agent/config.py`: `llm_max_tokens`(8000), `llm_connect_timeout_s`(5), `llm_read_timeout_s`(240), `llm_max_retries`(1). 모두 환경변수로 바꿀 수 있다.
- `agent/src/semantic_agent/agent/build.py`: `ChatOpenAI`에 위 값을 넣음. 전에는 출력 상한이 없고, 대기 제한이 없고, 재시도가 라이브러리 기본값(2)이었다.

## 값의 이유
- 출력 상한 8000: 같은 계열 모델(Gemma 4, vLLM)을 쓰는 다른 운영 사례에서 상한이 없을 때 한 응답이 같은 말을 되풀이하며 7분 넘게 14,000토큰을 쓴 기록이 있다. 일반 응답의 상한으로 8000을 쓴 기록을 따랐다. 문맥 한도를 실측한 뒤 다시 정한다.
- 연결 5초: 모델 서버가 사라졌을 때 바로 실패로 떨어지게.
- 응답 대기 240초: 같은 사례에서 정상 응답이 6.9~74.5초였고 그 3배 남짓. 질문 전체 마감(`ask_timeout_s` 300초)보다 짧아야 한 번은 다시 시도할 수 있다.
- 재시도 1회: 대기 제한 240초 × 기본 재시도 2회면 질문 마감을 넘는다.

## 잰 것과 안 잰 것
- 잰 것: `tests/test_model_limits.py` 1개 통과(설정이 모델 객체에 들어가는지).
- 안 잰 것: 실제 Gemma 4 응답 시간 분포, 8000 상한에 잘리는 응답 비율. Colab이 꺼져 있어 재지 못했다.
