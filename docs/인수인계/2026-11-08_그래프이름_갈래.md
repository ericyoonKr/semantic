# 작업 인수인계 — 2026-11-08 그래프 이름에 묶음 갈래 붙이기

## 왜

헌법 묶음(`legal-concept-constitutional-2026-11-07`)과 민사 묶음(`legal-concept-civil-2026-11-08-2`)이 둘 다 그래프 이름 `concept_frame`을 써서, 서버 기동 때 뒤에 읽힌 헌법 묶음이 「graph name appears in more than one bundle」로 꺼졌다.

## 정한 규칙 (사용자 결정 2026-11-08)

- 그래프 이름 = `묶음 갈래/매니페스트의 그래프 이름`. 예: `legal-concept-civil/concept_frame`.
- 묶음 갈래 = 묶음 이름에서 끝의 `-YYYY-MM-DD`와 그 뒤의 선택적 `-N`을 뗀 것. 날짜 꼬리가 없으면 이름 전체가 갈래다(`semantic-rules` → `semantic-rules/CLAIM_국가배상`).
- 같은 갈래의 묶음이 여럿이면 날짜, 그다음 `-N`이 가장 늦은 것 하나만 싣고, 나머지는 「같은 갈래의 새 판이 있음」 사유로 꺼진 묶음 목록에 올린다. 꺼진 옛 판은 sqlite로 바꾸지도 않는다.
- 다른 갈래는 매니페스트의 그래프 이름이 같아도 함께 싣는다.
- 한 묶음 안에서 그래프 이름이 겹치면 전처럼 그 묶음을 끈다.
- 매니페스트에 `source_bundle`이 있고 폴더 이름과 다르면 그 묶음을 끈다(사유 「manifest source_bundle does not match the folder name」).

## 바꾼 곳

- `crates/kg/src/naming.rs`(새 파일): 날짜 꼬리 떼기, `bundle_branch`, `graph_name`, 갈래마다 가장 늦은 판 고르기.
- `crates/kg/src/sync.rs`: 옛 판을 먼저 걸러 끄고, `source_bundle`을 확인하고, 그래프를 `갈래/이름`으로 싣는다.
- `crates/kg/src/set.rs`: 카탈로그의 `graph`를 sqlite 메타가 아니라 실을 때 정한 `갈래/이름`으로 채운다. sqlite 파일 자리(`sqlite/<묶음>/<그래프>.sqlite`)와 메타 `graph`(매니페스트 이름)는 그대로라 기존 캐시를 다시 만들지 않는다.
- `crates/kg/src/manifest.rs`, `error.rs`, `lib.rs`: `source_bundle` 읽기, 사유 두 개, `bundle_branch`·`graph_name` 공개.
- `crates/server/src/rules/load.rs`: 요건 트리 묶음은 카탈로그에서 `graph_name("semantic-rules", 트리 이름)`으로 검증값을 찾는다. 판정 엔진 안의 트리 열쇠(청구 유형 `CLAIM_…`)는 그대로다.
- 시험: `crates/kg/tests/branch.rs`(새 파일), `crates/kg/tests/{query,sync}.rs`, `crates/kg/tests/fake/bundle.rs`, `crates/server/tests/kg.rs`, `crates/ruleloader/src/emit.rs`의 그래프 이름을 새 꼴로.
- 바꾸지 않은 곳: 모양·계약·필드 표는 모양으로 고르므로 그대로다. 짧은 번호표와 상태 확인은 그래프 이름 문자열을 열쇠로 쓰므로 새 이름이 그대로 들어간다. `/kg/find`·`/kg/expand`·`/kg/state-check`는 그래프 이름을 JSON 본문으로 받으므로 `/`가 들어가도 경로가 깨지지 않는다. 에이전트 코드와 프롬프트에는 그래프 이름 예시가 없어 고치지 않았다.

- 호환 코드는 넣지 않았다.
- `progress_text`는 카탈로그에 없는 그래프 이름을 「그래프가 바뀜 — 다시 확인」으로 표시하지 않는다. 옛 이름 `concept_frame`으로 적힌 줄은 표시 없이 그대로 나온다(실측).

## 스펙에 없어 정한 것

1. 날짜 꼬리는 숫자 자리 모양(`-dddd-dd-dd`)만 보고 실제 날짜인지는 확인하지 않는다.
2. `-N`이 없는 판은 N=0으로 본다. 그래서 `x-2026-11-08` < `x-2026-11-08-1`.
3. 날짜와 N이 같은 두 이름(예: `-1`과 `-01`)은 이름 순서가 뒤인 것을 싣는다.
4. 날짜 꼬리를 떼면 갈래가 빈 문자열이 되는 이름(`-2026-11-08`)은 이름 전체를 갈래로 본다.
5. 날짜 꼬리가 없는 묶음(`x`)과 같은 갈래의 날짜 있는 묶음(`x-2026-11-08`)이 함께 있으면 날짜 없는 쪽을 옛 판으로 보고 「같은 갈래의 새 판이 있음」으로 끈다. 날짜 있는 묶음이 없으면 날짜 없는 묶음은 그대로 싣는다.
6. 가장 늦은 판이 다른 이유로 꺼져도 옛 판으로 물러나 싣지 않는다.
7. 매니페스트에 `source_bundle`이 없으면 폴더 이름을 묶음 이름으로 쓴다(요건 트리 묶음 `semantic-rules`의 매니페스트에는 없다).
