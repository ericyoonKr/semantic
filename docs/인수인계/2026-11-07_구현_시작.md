## 에이전트가 스펙에 없어 정한 것 (확인 필요 — 구현지시서 R에 더할 것)

- docmodel: 쪽 번호 줄 판별 정규식, 쪽 표시 형식(`--- pN ---`), 목차의 「제N조」 수준(직전 제목 수준 + 1), 인용 대조의 공백·NFC 규칙.
- agent: `memory/store.py`의 연결 풀 공유(`open_pool`), 업로드 마감 180초, 지식그래프 응답 칸 이름, `Assumption.value`는 bool.
- kg: 허용 관계 = `contract.relations` 키 ∪ `optional_relations`, 비순환 표시 칸, 상태 수 세는 법, 같은 그래프 이름이 여럿이면 묶음 이름 순.
- parsers: 「MB」 = 1024×1024, 시간 제한 기본 없음, 오류 갈래 배정, 쪽 나눔 연속 처리, 자동 번호 규칙, 각주 순서, HWPX 표 경로.
