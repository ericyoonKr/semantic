# 2026-11-08 법령 약칭으로 찾기

## 바꾼 것
- `crates/lawnames`(새 크레이트): 약칭 대응 파일(형식 `law-aliases/1`)을 읽어 약칭 → 법령ID를 찾는다. 열쇠는 공백을 모두 떼고 가운뎃점 변형(ㆍ・‧∙)을 「·」로 맞춘 글. 같은 열쇠가 두 번 나오면 읽기를 거부한다. 표기 전체가 약칭과 같을 때만 대응한다(「구 헌법」은 대응 안 함).
- `crates/retrieval/src/query/laws.rs` `resolve_law`, `crates/lawtime/src/versions/pg.rs` `find_law`: 정식 이름·법령ID로 못 찾았을 때만 약칭 표를 본다.
- 서버 ①: 환경변수 `LAW_ALIASES`(파일 경로)를 기동 때 읽는다. 없으면 경고만 하고 약칭을 풀지 않는다.
