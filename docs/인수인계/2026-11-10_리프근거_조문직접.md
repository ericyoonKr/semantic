# 2026-11-10 리프 근거 자료를 리프에 적힌 조문으로, 상당인과관계 명제 바꿈

## 왜
- 실제 Gemma로 국가배상 판정을 돌리니 리프마다 붙는 [근거 자료]가 명제 글로 법령을 검색한 결과라 엉뚱했다(손해 리프에 언론중재법·실용신안법·디자인보호법 조문).
- 상당인과관계(R8) 명제 「…가 없었다면 … 생기지 않았고, … 통상적이다」에 Gemma가 프롬프트를 고친 뒤에도 늘 「모름」을 답해, 손해·영조물 하자가 참이어도 결론이 유보됐다.

## 바꾼 것
- `crates/engine/src/deps.rs`: `AuthoritySearch::cited(evidence)` 추가(기본은 빈 결과). `crates/engine/src/slices.rs`: 리프에 근거 조문(evidence)이 있으면 `cited`로 그 조문을 읽고, 하나도 못 읽었을 때만 지금처럼 명제 글로 검색한다.
- `crates/server/src/deps/authority.rs`: `cited`를 구현 — 근거의 「제N조제M항」을 조 단위(「제N조」, 「제N조의M」)로 줄여(조문 읽기가 항 단위를 받지 않음) 같은 법령·조는 한 번만 현재 판본을 읽는다. 못 읽은 조문은 기록하고 건너뛴다.
- 요건 트리(저장소 밖 `semantic-data/rules/claim_국가배상.yaml`, 원본 백업 `.bak-20261110`): R8 명제를 「그 직무집행행위나 영조물의 하자 때문에 그 손해가 생겼다」로 바꾸고 규칙 적재기로 다시 발행(사용자 결정).

## 잰 것
- R8 명제(새 프롬프트, 사건 다섯, 정답은 내가 붙임): 그전 명제 — 포트홀·경찰 폭행 둘 다 「모름」(참이어야 함). 새 명제 — 둘 다 「참」, 스스로 넘어짐(하자 없음) 「거짓」. 퇴근 뒤 사고 「거짓」, 군인 훈련 중 순직 「참」으로 답했는데 이 둘은 내가 붙인 정답(모름)이 틀렸을 수 있다.
- 실제 Gemma로 국가배상 질문(포트홀 문서): 입증책임을 적용한 결론이 「불성립」 → 「성립」(제5조 갈래: 영조물 하자·손해·인과관계 참). 입증책임을 적용하지 않은 결론은 항변 사실이 문서에 없어 「결론 유보」. 판정 불가 리프 14개 → 12개.
- 시험: engine 전체, server 단위(조 단위 줄이기) 1개, `server --test judge` 7개 통과.

## 남은 문제
- 판정 뒤 에이전트가 조사 하위 에이전트를 두 번 더 부르고(전체 52초), 판정에서 「모름」인 고의·과실을 「가능성이 있다」고 덧붙였다. 판정 문장 밖의 결론을 막는 장치는 아직 없다.
