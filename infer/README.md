# infer — ② 추론 서버 구성 (PROJECT.md §5 ②)

C++ 코드를 새로 짜는 곳이 아니라, llama.cpp(또는 onnxruntime) 프로세스를
구성해 띄우는 곳. Rust 백엔드(retrieval::embed_client)는 HTTP로만 접근한다.

여기에 기록할 것:
- 확정된 임베딩 모델명·출처·차원 (★ 코퍼스 임베딩과 동일 모델 — §12 실측 1)
- 기동 방법 (run_llamacpp.sh), 포트, 헬스체크 경로
- 처리량 실측 (배치 크기별 지연) — 업로드 청크 배치 크기 결정의 근거
- 서버 다운 시 백엔드 동작: FTS 단독 강등 (§11) — 여기 장애가 전체 중단이 아님
